# 남해 스마트 경로당 통합 플랫폼

경로당의 콘텐츠·공지 표출과 운영자의 시설물·이벤트·스케줄·통계 관리를 연결하는 웹 플랫폼입니다. 여러 개발자가 함께 구축한 프로젝트에서 프론트엔드와 백엔드 기능 개발, 외부 시스템 연동, 운영 개선에 참여했습니다.

## 담당 역할

### 화면과 서버 기능 개발

- **경로당 콘텐츠 대시보드:** 날씨·YouTube 조회와 갱신 API, 정기 갱신 작업, 화면 표출 및 콘텐츠 롤링 개선
- **스케줄·미디어 관리:** 스케줄 등록·수정, 캘린더와 대상 경로당 선택, 이미지·영상 업로드, 일반·긴급공지 처리와 온보딩
- **운영 통계·GIS:** 차트, 지도와 지역 목록의 상호작용, 날짜 검색, 통계 조회와 엑셀 다운로드
- **공통 기능:** 공통코드·사용자 정보·시스템 목록 조회와 로그인 인터셉터 등 인증 연동

### 공동 기능의 연동과 개선

- 이벤트 전파 화면, SMS·마을방송 대상 선택과 결과 확인 UI
- 화상회의 참여·종료 버튼과 상태 처리, 소방 대응 화면 개선
- CCTV 조회 및 좌표 일괄 조회, 시설물 검색 상태 유지와 실시간 갱신 개선
- WebSocket 재연결과 중복 처리 정리, 프론트·서버 구조 리팩토링 및 운영 오류 수정

시설물 초기 구현, 이벤트 공유 백엔드, 화상회의 자동 로그인·자동 종료 등에는 다른 개발자의 구현이 포함돼 있습니다. 해당 영역의 기여는 직접 변경한 화면·연동·개선 범위를 기준으로 설명합니다. 기존 공통 제품과 외부 SDK의 개발을 본인 성과로 포함하지 않습니다.

## 주요 화면

| 화면 | 경로 | 역할 |
| --- | --- | --- |
| 운영 대시보드 | `/ssc/sc/mng` | 권한에 따른 홈·이벤트·시설·스케줄·통계 및 소방 대응 |
| 경로당 콘텐츠 | `/ssc/sc/social/…` | 날씨·영상·버스 등 콘텐츠 표출 |
| 경로당 공지 | `/ssc/sc/noti/…` | 대상별 공지 표출 |

운영 화면은 사용자·권한 정보와 API 응답을 사용합니다. 콘텐츠·공지 화면은 대상 식별자 등 서버 연동 조건도 필요합니다. 소스의 라우팅 구조를 설명한 경로이며, 화면 서버만 실행해 운영 기능을 모두 사용할 수 있는 것은 아닙니다.

## 폴더 구조

```text
front/
  src/component/
    api/            # 서버 API 호출
    lib/            # 클라이언트·주소·공통 처리
    stores/         # 화면 상태
    pages/manage/   # 운영·시설·이벤트·스케줄·통계·소방 화면
    pages/social/   # 경로당 콘텐츠
    pages/noti/     # 공지 표출
  src/assets/       # 예시 이미지·무음 오디오·CCTV 데모 어댑터
src/main/java/com/eseict/ssc/
  facility/         # 시설물
  schedule/         # 콘텐츠·공지·스케줄
  stat/             # 운영 통계
  user/             # 사용자·인증 연동
  conf/ fire/ sms/   # 회의·소방·전파
  open/             # 외부 데이터 연동
  socket/ websocket/ scheduler/
docs/               # 공개 범위와 연동 조건
```

## 화면 설치와 빌드

Node.js 22.12 이상 또는 24를 사용합니다.

Windows에서 압축 해제 경로가 너무 길면 실패할 수 있으므로 짧은 작업 폴더를 사용합니다.

```sh
cd front
npm ci --legacy-peer-deps --ignore-scripts
npm run typecheck
npm run build
npm run dev
```

화면의 API·WebSocket 연결 기본값은 로컬 주소입니다. `front/.env.example`을 참고해 로컬 API 어댑터 주소를 설정합니다. 클라이언트 환경변수에 인증 비밀값을 넣지 않습니다.

API·권한·세션·모의 데이터 서버는 포함하지 않습니다. 실제 서버를 연결하지 않으면 데이터 화면이 비어 있거나 API 요청이 실패할 수 있습니다. 사용자 권한 검사를 제거한 데모 로그인이나 운영 인증 우회 기능도 추가하지 않았습니다.

## 서버 소스와 연동 조건

서버 코드는 기능·레이어 구성을 확인하기 위한 참고 소스입니다. 사내 공통 라이브러리, 복수 DB 스키마와 데이터, OMS·화상회의·시설 모듈 등의 연동 구현이 별도로 필요합니다. 사내 Maven 주소, 라이브러리 바이너리와 운영 설정은 제공하지 않습니다.

`src/main/resources/application.yml.example`은 환경변수 사용을 설명하는 최소 예시이며 전체 서버 실행 설정이 아닙니다. 서버 빌드와 실제 DB·외부 시스템 연동은 검증하지 않았습니다.

## 공개 범위

- 사내 최신 코드의 기능 구조를 기준으로 정리한 소스 사본이며, 과거 Git 이력은 포함하지 않습니다.
- 운영 주소·고정 인증 문자열·실제 DB 설정·운영 JSON과 업로드 파일을 제외했습니다.
- 원본 이미지·지도 이미지·아이콘은 생성한 예시 자산, 알람 음원은 무음 파일로 대체했습니다. 원본 폰트와 영상은 제외했습니다.
- CCTV SDK는 외부 통신을 하지 않는 데모 어댑터로 대체했습니다. 실제 CCTV 재생을 제공하지 않습니다.
- 소스와 의존성은 [공개 범위와 연동 조건](docs/PUBLIC_SCOPE.md)에 따라 구분했습니다.

## 검증

타입 검사와 프로덕션 빌드를 확인했습니다. npm 의존성 보안 검사 결과와 공개 사본 검증 결과는 로컬 점검 보고서에 기록합니다. 화면 빌드 통과는 실제 인증·DB·CCTV·회의·전파 기능의 종합 검증을 뜻하지 않습니다.
