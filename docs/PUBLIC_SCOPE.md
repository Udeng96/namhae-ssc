# 공개 범위와 연동 조건

## 기준과 기여

- 사내 `develop_2026`, 커밋 `c9c31f1fcfa88f6d04fb9cae8a1cdd3c5fbd3321` 기준입니다.
- 공동 개발 프로젝트입니다. README의 본인 기여는 `JangYouJung`·`Udeng96` 작성자의 비병합 커밋과 대표 변경 내용을 근거로 정리했습니다.
- 커밋 수는 작업량·기여율이나 기능의 독점 소유권을 뜻하지 않습니다. 병합 커밋은 다른 작성자의 구현을 본인 구현으로 계산하는 근거로 쓰지 않았습니다.
- 원본 커밋 메시지·작성자 이메일·회사 Git 주소·변경 이력은 이 공개 사본에 포함하지 않습니다. 기능별 근거는 별도 로컬 분석 자료에 보관합니다.

## 제외·대체

- GitLab CI·배포 설정, 에이전트 설정, 원본 운영 문서·스크립트, 추적된 node_modules와 target을 제외했습니다.
- 실제 환경 YAML, 운영 JSON, 업로드 미디어, 사내 라이브러리 바이너리와 원본 SDK를 포함하지 않습니다.
- 원본 이미지·아이콘·지도 그림은 생성한 예시 이미지로 교체했습니다. 알람 파일은 무음 WAV이며 영상·폰트·소스맵은 제외했습니다.
- 운영 IP·회사 호스트, 고정 인증 문자열과 비밀번호 로그를 제거했습니다. 원본 CCTV 식별자의 일부 상수는 예시 식별자로 대체했습니다.
- API·WebSocket 게이트웨이는 환경변수 또는 loopback 기본값으로 분리했습니다. 서버에만 있어야 할 인증 비밀값을 브라우저 환경변수로 옮기지 않았습니다.
- 원본 연동 경로·인터페이스는 구현 구조를 설명하기 위해 남아 있습니다. 실제 서버·네트워크·데이터를 제공한다는 뜻은 아닙니다.

## 서버의 제한

- `com.eseict:common-utils` 등 비공개 의존성을 사용하는 import와 Maven 선언은 참고 소스의 일부로 남습니다. 해당 라이브러리 코드·JAR·사내 다운로드 주소는 제공하지 않습니다.
- primary·SMS·방송 등 다중 데이터소스와 다수의 설정이 필요합니다. 최소 application 예시는 완성 실행 설정이 아닙니다.
- API 키·암호화·OMS·회실·시설 모듈·메시지 수신 연동은 독립적인 어댑터와 검증이 필요합니다. 외부 시스템을 흉내 내는 가짜 보안·암호화 구현은 추가하지 않았습니다.
- Java·Maven 실행 환경이 없어 서버 빌드·테스트는 수행하지 않았습니다. 운영 시스템에 연결해 검증하지 않았습니다.

## 화면 변경

- 설치 스크립트를 운영체제에 의존하지 않도록 정리했습니다.
- 사용하지 않는 npm 패키지를 제외하고 의존성을 업데이트했습니다. Vite 7과 React Router 7을 사용합니다.
- Zustand의 Immer 미들웨어에 필요한 `immer`를 명시적 의존성으로 추가했습니다.
- 통계 CSS에서 선택자 없는 잘못된 선언 블록을 제거했습니다.
- 설치 시 기존 프로젝트의 peer 의존성 조건에 맞춰 `--legacy-peer-deps`를 사용합니다.
- 종합 화면 조작·실제 권한별 흐름은 API와 모의 데이터 서버를 갖춘 뒤 별도 확인해야 합니다.

## 공개 ZIP

공개 ZIP에는 소스·예시 자산·설정 예시·README와 문서만 넣습니다. 원본 Git 이력, 로컬 원본 사본, 감사 보고서의 비공개 원본 값, node_modules와 dist는 넣지 않습니다.
